Detailed Description

Driver class for the XPT2046 4-wire resistive touch screen controller.

The XPT2046 is a 4-wire resistive touch screen controller featuring a 12-bit 125 kHz SAR Analog-to-Digital Converter (ADC). It interfaces with the microcontroller via SPI and asserts an active-low interrupt signal (PENIRQ) whenever touch contact is detected.

Inherited Classes & Module Origins

  • ResistiveTouch (from hal/ResistiveTouch.h in the yss OS HAL layer): Provides calibrated coordinate conversions (calculateX(), calculateY()) and pointer event dispatching (pushDownEvent(), pushDragEvent(), pushUpEvent()).
  • Trigger (from yss/Trigger.h in the yss OS core system): Enables asynchronous execution in an independent OS thread. The virtual function trigger() is overridden to handle debouncing, continuous coordinate sampling while pressed, drag notification, and release detection.

Example Usage

#include <module/XPT2046/XPT2046.h>
XPT2046 touch;
TouchEventDispatcher dispatcher(20, 2048);
void initializeTouch(void)
{
// Configure GPIO pins and SPI peripheral beforehand.
XPT2046::config_t touchConfig =
{
spi0, // Spi &spi;
{&gpioC, 3}, // pin_t chipSelect;
{0, 0}, // pin_t busy; (optional / not connected)
{&gpioC, 5}, // pin_t isr; (PENIRQ pin)
};
touch.initialize(touchConfig);
dispatcher.setPointerDevice(touch);
}

Locks the SPI bus mutex and applies the 2 MHz Mode 0 SPI specification. Asserts the Chip Select line (low) and transmits the 8-bit control byte specifying channel, 12-bit resolution, and power mode. Pauses for 100 us to allow the internal SAR ADC conversion to settle. Clocks out the 12-bit result across two byte transfers (MSB-aligned in bits [11:5] of the first byte and bits [4:0] of the second byte). Deasserts Chip Select (high) and unlocks the SPI bus.

Spawns a Trigger execution thread with a 512-byte stack and configures falling-edge interrupt on the PENIRQ pin.

Stores the SPI peripheral pointer and GPIO pin assignments (Chip Select, Busy, ISR). Activates the Trigger thread with a 512-byte stack size for asynchronous touch processing. Configures the ISR GPIO pin (PENIRQ) for falling-edge detection and enables its interrupt. Sets the Chip Select pin high (inactive), introduces a 100 ms stabilization delay, and performs an initial conversion on the X-channel to power up the internal ADC and re-enable PENIRQ.
